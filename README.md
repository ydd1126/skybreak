# 开天 · Skybreak

> **开天辟地** —— 苹果从没支持过这代硬件（Arrow Lake），我们把这条路开了出来。
>
> 英文代号 **Skybreak**：sky（天）+ break（破）。
>
> 平实别名：**黑果通**（黑苹果 + 一路通）。两个名字都认。

一句话装机：用户说「**开天，帮我装 macOS 26**」，agent 跑 `scripts/install-macos26.ps1`，
用户只做 3 个物理动作（BIOS 9 项 / 装机 3 击 / 开箱向导），装完双击一个 `.command` 装显卡驱动。

## 名字为什么是这两个字

| 字 | 表面 | 里子 |
|---|---|---|
| **开** | 开始、开启 | 打开一个苹果封死的平台；把"卡死"打开成"通" |
| **天** | 天空、天险 | 苹果的天险（CPU 不支持、GPU 无驱动、PCH 不认）；Skybreak 的 sky |

合起来就是这套东西干的事：**在苹果画的红线之外，开出一条能走的路。**

## 它是什么

不是教程，是**一台真机四天实战压出来的施工档案 + 可执行验收**：

- 知识在 `references/`（6 份，998 行）
- 判断在 `SKILL.md`（989 行，第〇节是 agent 执行剧本）
- 而 `scripts/` 里的工具会**拒绝**写出体检不通过的盘 —— 这是它和"网上教程"最大的区别
